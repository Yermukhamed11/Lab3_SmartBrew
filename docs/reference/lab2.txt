User Stories
• As a Customer, I want to look at the digital menu so that I can see the coffee choices
  and prices.
• As a Customer, I want to use sliders to change the amount of sugar and milk so that
  the drink tastes the way I like.
• As a Customer, I want to pay with a contactless card or phone so that paying is fast
  and easy.
• As a Customer, I want the AI to suggest a drink based on the weather and time so
  that I can try something new. (Custom Feature)
• As a Customer, I want to see a progress bar so that I know when my coffee is ready.
• As a System Admin, I want to edit the menu so that I can add new drinks and keep it
  updated.
• As a System Admin, I want to get an alert when ingredients are low (below 15%) so
  that I can refill the machine in time.
• As a System Admin, I want to see daily sales reports so that I know which drinks sell
  best.
• As a Maintenance Technician, I want to run hardware tests on pumps and heaters so
  that I can find broken parts easily.
• As a Maintenance Technician, I want to save error logs to a USB drive so that I can
  check them on my computer.
